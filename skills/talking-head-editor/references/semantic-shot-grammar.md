# 语义镜头与参考风格精修

用于用户明确选择《反解》及同类混合讲述风格。先保留题材、原声与口语性：生活吐槽不改成商业史讲解，不为套风格生成不存在的资料、医学机制或新台词。参考依据见 fan-jie-evidence.md；其中未试听的声音手法不作为已证实目标。

## 先诊断，再修改

比较双方承担同一任务的段落，不按时长硬配同一秒。写出“参考段观察→当前段表现→影响→可执行改法→验收画面”。没有全片逐帧/逐句证据就不报风格百分比、硬切占比或精确声音结论。

本次观察到的典型差距：

| 参考位置 | 当前容易出现的问题 | 优化方向 |
|---|---|---|
| 00:05–00:09，文章重点句推近关键词 | 全屏素材上始终只有顶部大字 | 先给对象或原文，再突出其一处细节；推近停在明确阅读目标 |
| 01:43–01:50，书桌对象与文字分步出现 | 主体、结论、连线第一帧全部铺满 | 按原声建立主体→动作/关系→结论，后出现元素必须增加信息 |
| 02:58–03:03，真人连续表达 | 每段真人都附加大标题 | 在判断、转折、反应段让表情和对白承担信息，删去重复标题 |
| 03:40–03:52，旧卡片返回参与比较 | 重播旧画面，但没有新的比较任务 | 保留可识别的旧对象，与新状态同场或紧邻出现，指出究竟变了什么 |
| 04:02–04:14，实物卡到循环关系 | 素材只是一个名词的插图 | 按语义选择数量积累、用途、对比、流程或反馈；不要见箭头就声称因果 |

“高级”落实在阅读路径、对象关系、时机和统一材质。增加噪点、泛光、英语装饰或素材数量不能代替这些工作。

## 分镜必须说清六件事

为需要包装的语义单元记录以下字段，可写在制作计划旁，不直接传给基础渲染器：

1. **原话及时间**：源片区间、成片区间、词或短语出现的位置、定位依据与不确定处。
2. **任务**：观众要理解的对象、动作、对照、因果、情绪或比喻；关系不能比原话更强。
3. **画面角色**：谁是当前主体、哪些是背景线索、哪里是真实证据，哪里只是示意。
4. **出现顺序**：建立全貌→引入新信息→聚焦或比较→留出阅读→回真人/下一事件。按需要取其中几步，不要求每镜头五步齐全。
5. **焦点与退出**：运动起点、落点、停稳时间；当前重点何时退下，下一句为什么接这个画面。
6. **回调对象**：首次出现的素材标识、后段再用时间、需要呈现的新增关系。没有叙事收益就不回调。

## 选画面时区分作用

- 情绪、自嘲、判断：优先真人，保留有用停顿。已经有内嵌字幕时不要再把同义标题铺满头顶。
- 具体动作：用动作可见的 B-roll。通勤要看到交通/移动；泛城市天际线不能自动承担通勤动作。
- 可查证的数字、引语或产品：查来源，先给必要上下文，再局部聚焦。生活比喻不伪装成研究结论或检测报告。
- 抽象词：先确定可见的物体、行为、约束或对照。AI 场景可补拍摄缺口，生成图片加推拉要称为图片后期运动。
- 两种状态：复用同一主体或同类构图，保持标签对应。箭头需能读出切换、类比或流程含义，别把同时发生画成因果。

素材可用时才进入合成。沿用已取得且适配的素材；不足时完成必要检索、下载和包装。继续保留来源、许可、修改和示意属性，不能从“免费可下载”推导可任意发布。

## 字幕时机与构图

对白字幕、视觉重点、来源标记分工。章节名短且克制；重点随原话出现，提前显示结论会破坏铺垫。缺词级时间时可依据校对后的短句字幕先定位，再对入场前后加密核对，不声称精确重音对齐。

避免把“标题→小英文→图片→解释句→对白”变成全片固定模板。可让词贴近对应物体、从资料行中高亮、进入对照两侧，或只保留对白。常规旁白段无需同时展示三层同义文字。

横屏参考迁移到竖屏时，重新安排视线与空间；脸已占画面大半时不要照搬真人左右多张卡。可以使用全屏关系画面后返回真人，或保留更少对象。浅色纸面使用无黑色外描边的深字，深色实拍按实际背景决定轻描边。

## 动作和节奏

运动必须能用一句话解释目标，如“从原文推到这三个字”“把旧对象退到次要位置，让新状态进入”。有字的卡片尽早停稳；只有背景或仍在发生的真实动作可以持续运动。不要每张卡都摇摆或一直缓慢漂移。

主要事件之间可直接切换；对象仍有同一性时，可用整图退成照片卡、卡片局部放大、少量画面覆盖。物体真实遮挡镜头、图形覆盖和二维缩放分别命名，不从效果倒推原片软件或插件。

声音包装与视觉独立验收。新音效需配合确有动作的重点；不把技术电平正常等同于听起来合适。未回听参考片时不模仿臆测的音乐、音桥或卡点。

## 可复用的交付与复核

升级 skill 时先实现规则/工具，再用真实素材的代表段验证，不默认重剪整片。代表段覆盖“原声→解释画面→原声”或一种明确新增能力；标注短片范围，不能用几个美观截图证明全片已达到参考。

复核入场初帧、聚焦中段、停稳后、返回真人：标签和对象对应；关键词未抢跑；过渡中对白保持一套且对比度足够；旋转卡边角和标识保留；旧对象可识别；字幕空间不被其他标签占用。若每个画面仍是相同布局，回到分镜检查其任务，而不是随机换色或加转场。
