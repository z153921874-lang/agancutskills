# 从纯真人口播制作混合讲解成片

输入只有真人与声音时使用。用户已有参考风格就沿用；当前会话的《反解》表示“真人＋资料＋图解”的方向，不要求复制作者台词、全部特效或商业故事结构。

## 输入与叙事边界

最低输入是有声口播视频。稿件可辅助校对，缺稿先本地转录。已说出口的声音是当前可剪素材；只在文字稿里新增的过渡句没有对应原声。默认用删减、调序、标题卡补充上下文；若缺关键论述，明确指出需要补录或用户授权另加旁白。不能换字幕假装真人说过新台词，也不能把后一句剪接成相反观点。

先检查声音清晰度、时长、画面比例、人脸和字幕安全区。用途/比例从已有要求推断；未知时先沿用原比例。已有清晰品牌要求才换配色，缺素材不要让用户先整理全套资源才能开始。

## 制作顺序与每步产物

1. **建立可编辑文案**：保存原始转录与校对稿；核对名称、数字、否定和术语。标记源时间、句子任务、完整观点和可删部分。
2. **剪顺原声**：先出保留区间与时间映射，再安排新画面。用 map_captions.py 重映射词级字幕；切词警告需回到剪口处理，不能只隐藏字幕。
3. **逐句分镜**：读 hybrid-storytelling.md，给每个语义单元写“观众应理解什么”，再选真人、资料、B-roll或图解。判断/反问优先留真人；术语用对象与用途，因果用箭头，比较用同尺度卡片。不要按固定秒数换画面或承诺真人/B-roll固定占比。
4. **准备素材**：建立素材表，区分已就绪、待查找、待制作、可回退。自行完成授权范围内的资料检索和图解制作。网络图片/视频先检查实际访问与使用条件；不能把网页搜索缩略图当成已拿到高清可用素材。工具无下载/导出能力时用已授权本地素材或原创图形替代，不绕过显示或访问限制。付费购买、私密账号访问按实际需要处理，不承诺资源免费齐全。
5. **确定视觉样式**：先选少量颜色、字体层级、资料卡边框和图解底图；同一素材尽量用于后段回调比较。可做20—30秒代表片段，检查后自行迭代并继续全片；除非用户要求先审样片，不把样片设成必需等待确认的关卡。
6. **分层合成**：准备就绪的分镜可先按 storyboard-compiler.md 调用 compile_storyboard.py 生成计划，处理检查报告，再补充完整对白字幕。保留剪顺的原声音轨为主轴。全屏资料/B-roll覆盖真人画面时仍播放原口播；叠层本身默认不带音，避免回声。小字幕、关键词、图片、视频各按成片时间放置。优先硬切和简单推拉；复杂透视、精细蒙版先准备合格素材或另行实现，不填入未支持字段。
7. **声音与验收**：先确保原声连贯，再加合法可用配乐和少量有作用的音效。侧链压低需真人片段回听。逐段检查切口、词句同步、遮脸、资料可读性、图解方向、素材与事实对应；不能把技术测试当成已试听。
8. **交付**：MP4、对白字幕、剪辑计划、源时间映射、素材表、分镜及未完成的验收项。用户要可编辑剪映草稿时单独验证接口，不用JSON/SRT冒充剪映工程。

## 素材表与分镜

每个素材记录：`id, purpose, type, source, local_path, evidence_or_illustration, status, fallback`。证据需可追溯来源；原创图解/AI场景是示意。已生成文件不等于内容已经核实。

每个分镜记录：`源片区间、成片区间、原话、句子任务、观众所得、画面设计、素材ID、字幕重点、动作、转场、回调对象、制作状态、验收项`。这不是渲染计划格式；最终转换为已支持的 clips/texts/overlays/effects/audio。

| 缺的内容 | 默认补法 | 仍缺时 |
|---|---|---|
| 干净图解 | make_diagram.py或本地图形工具制作 | 真人＋准确关键词 |
| 新闻、人物或产品证据 | 查找可追溯资料并取得可用素材 | 保留解释，删除无法支持的视觉暗示 |
| 工作/场景B-roll | 授权素材、可用本地视频、原创场景 | 静态示意加轻运动 |
| AI辅助场景 | 读取当前图像技能并调用可用工具，文字另排 | 使用原创图形，说明风格变化 |
| 新过渡句 | 优先重新组织已有句子 | 标出补录点；不伪造口型和原声 |
| 精细抠像或遮挡 | 先短片检验质量 | 全屏资料覆盖或普通卡片 |

## 当前完成度的表述

可以制作相同类别的混合讲解视频，但能否达到参考片完成度取决于文案、可用资料、图形设计与迭代。技能已提供制作流程、基础图解、分镜转换；v2.5渲染器补充完整缩入与卡片缓动停留。此前只做过各功能短片测试，没有据此验证任意纯口播输入都能自动变成参考级完整成片。不能说一键同款、固定复刻百分比或已经自动完成事实核查。
