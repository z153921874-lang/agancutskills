# 基础图解素材生成

用 `scripts/make_diagram.py --spec <JSON> --output-dir <新目录> [--font <字体文件>]` 将确定的文案生成1920×1080 PNG。依赖Pillow，默认Windows微软雅黑字体；其他机器显式提供字体。输出目录必须不存在。

支持三种类型：compare为2个节点；branch为中心对象＋3个用途；cycle为3节点有向循环。不自动从文案推导因果；箭头代表的关系必须先由编辑判断。短文案上限：标题24字、节点26字、分支中心14字、页脚52字。

```json
{"kind":"branch","title":"把抽象能力变成具体用途","center":"一项通用能力","nodes":["处理数据","辅助创作","支持协作"],"footer":""}
```

输出stage-01.png到stage-02/03.png，每张比前一张多一个节点；最终张展示完整关系。字号/底图/配色是基础样式，并非参考视频同款。当前参数不支持自定义布局、透视或动画曲线。需要更精细画面时制作额外素材，不把这个工具当成排版能力上限。

合成方式：在 render.py 的 overlays 中依次添加各stage图片，`still:true`，指定成片起止时间。图解充满画布时覆盖原视频但保留 clips 原音。1920×1080用width1920/height1080/x0/y0；竖屏不要直接填满导致裁切，应重新排版或保持16:9图放在不挡人脸和字幕的位置。

各阶段时长随对应口播决定，留出最终读图时间；不是固定每两秒切一张。现有叠层可以淡入、移动，但本脚本仅产出分阶段静态素材，不生成真正的线条生长动画。需要小字字幕时预留底部安全区域；资料来源文字不得被对白遮住。
