# 真人、资料与信息图混合口播

用于知识、商业故事、技术解释，以及需要把抽象卖点具体化的商品讲解。不要强迫普通访谈采用商业人物故事结构。参考观察见 [反解案例证据](fan-jie-evidence.md)。

## 先决定一句话要做什么

| 句子任务 | 优先画面 | 判断标准 |
|---|---|---|
| 设问、纠偏、判断、对观众建议 | 真人，必要时适度推近 | 表情/语气承担可信度，避免素材抢走判断 |
| 数字、名称、年份 | 数字卡、关键词、时间节点 | 单位与口径完整，重点一次只给一组 |
| 事件、原话、历史资料 | 有来源的照片、视频、网页局部 | 可追溯；排版成文件样式不代表是真文件 |
| 对象与用途 | 产品图＋分支箭头＋动作词 | 每个箭头说清关系，观众能回答“它能做什么” |
| 选择、取舍、前后变化 | 对比卡片、旧卡回调 | 两边使用同一比较尺度，身份与标签相符 |
| 积累、扩散、生态 | 多对象逐次出现、循环关系图 | 展示机制，不只放大“生态”二字 |
| 工作、投入、等待等动作 | 贴合句意的B-roll | 一段承担一个动作；不能暗示示意镜头是真实现场 |
| 缺乏现场素材的情境 | 可选插画/AI辅助场景 | 作为示意；不伪造合同、历史照片、实验或商品实测 |

推荐叙事起点：结果与矛盾 → 具体问题 → 选择及代价 → 转折 → 纠偏/机制 → 案例兑现 → 观众可做的事 → 回扣中心意象。按素材取舍，不强制凑全。术语优先翻译成动作与用途，少用形容词堆气氛。研究与事实核查另行进行，不能从参考视频的字幕直接认定事实。

## 把抽象词变成画面

1. 找出对象、动作、关系、限制条件：例如“通用能力”对应一个对象到多个用途，“生态”对应用户和产出的反馈循环，“不兼容”对应接口/对象不匹配。
2. 给出观众应看懂的一句话；没有明确解释目标就保留真人，不强配科技空镜。
3. 每个画面先主体、后关系、再结论；复杂图采用逐项显现，完成后留阅读时间。时长以词数、关系复杂度和实测可读性调整。
4. 连续内容可用同一底图推动视线；不要每句重置场景。前后对照优先复用旧卡，降低重新识别成本。
5. 主视觉对事实负责：产品外形、数据单位、箭头方向、前后标签与原话限定条件均需验收。

## 字幕与画面层级

- 对白字幕负责连续理解；动效词负责重音。一般每个语义单元挑一个短词组，不给所有字相同强调。
- 重点出现时可放大、滑入、变色或加高亮；以进入—停留—退出形成完整节奏。参数是起点，不是参考视频的精确复原。
- 资料阅读：保留整页或标题来源定位，再到局部重点；背景可压暗/模糊。不能模糊掉影响结论的限定条件。
- 中英混排和装饰纹理必须让位于中文可读性；识别字体是否可用，不能凭外观宣称同款字体已找到。
- 一个项目限定少量主色、字号层级、纸张/网格风格；按用户品牌改配色，不把案例的绿/黄设成通用默认。

## 转场决策

- 同一论述直接硬切；强句可用近景或资料切入。没有全片统计时不报硬切占比。
- 比较或解释关系改变，可用卡片位移、局部推拉；运动必须有明确目的地和阅读停留。
- 新画面推入覆盖旧画面属于画面覆盖转场；实物经过镜头造成的遮挡才标为实物遮挡。无证据不混称。
- 若制作实物遮挡：检查遮满时刻、切点与离场方向；没有前景蒙版/完整素材时回退硬切，不写不存在的API。
- 透视、景深、颗粒、色散是可选风格，不能每剪一刀都加。同源音轨继续与否需试听，不能靠抽帧推断J-cut/L-cut。

## 资产与执行

逐段记录 `time_range / line_task / viewer_takeaway / visual / asset_source / evidence_or_illustration / keyword / motion / transition / callback_to / renderer_support / qc`。这是分镜字段，不是 render.py 的JSON字段。

现有渲染器直接支持：基础图/视频B-roll叠层、字幕动画、平滑推拉、位移、模糊、音轨混合。网页高亮、关系板、循环图、透视纸卡等可先用图形工具制作素材，再按已支持字段组合；不要声称它们已变成原生一键效果。

如果用户要求AI辅助画面制作且图像工具可用，读取当前 imagegen 技能，生成不含密集文字的背景/情境，再由排版工具加准确文字；视频生成需单独可用工作流。只有分析请求时不自行生成、下载或购买素材。无法确定参考素材来源时标记“未知”，不标记“AI生成”。

商品讲解迁移：抽象的“舒适、显瘦、百搭”应对应可见面料/结构、版型对照或使用搭配，效果只能取自实际素材和已核实信息；AI示意不能冒充真人试穿与测试。
