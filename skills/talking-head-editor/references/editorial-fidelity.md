# 参考画面的素材质感、层次与段落编排

用于《反解》系列风格制作，以及用户认为界面、配图或排版简陋的返修。先确定问题来自素材、构图还是信息顺序；不要仅换配色。2026-10-12 的手机口播返修暴露了“简笔手机＋小图标＋右侧结论”的局限；此案例不等于所有图解都应换成照片。

## 素材先达到成片用途

- **关系结构**可用原创几何、线、箭头；**情境、人物表演、物体材质**优先用匹配的实拍、摄影或高质量AI示意。简单矩形、笑脸、方块人不自动替代后者。品牌图标、明确的扁平插画风格仍可用原生矢量。
- 并非都需要AI：先检查用户素材、已有可用资产与真实资料。缺摄影素材而采用几何回退时，明确其是风格回退；不要称为成熟参考式包装。
- 同一物件要有稳定 asset ID。尺寸、裁切锚点、屏幕区域、色调、边框和阴影分别记录。屏幕插图不能拉伸人脸；必要时采用留边或独立阅读镜头。
- 真人已有原字幕时，解释画面可全屏替换并重建校对对白。避免仅因原字幕存在就永远放小图在角落。涉及比喻、AI图或示意界面，保持适当标识。

## 设计一整段，不排列若干张字卡

先写出：当前实例→需要理解的区别/过程→每镜新增信息→焦点落点→返回真人的原因。至少比较这段是否仍反复使用相同位置、相同占幅、相同字体分量；若任务不同却版式相同，重新编排，而不是随机换皮肤。

实例的照片/镜头可以先占主画面，再退成卡片、成为节点或回到真人旁。既有内容不应每次完全重画。比较要保留共同尺度与身份线索；无数量依据时不画具有精确比例含义的图。

“背景先退，物件后移”与“物件先移开，真人再出现”可避免二维卡片穿过清楚的人脸；不是要求所有转场都分两步。选帧覆盖入场、途中、到位、退出，保护对象路径而不仅是最终位置。

新卡需要阅读时，先留出入场后的停稳时间。短台词最后才提到的补充项，可以沿用已有对象、保留真人或只在对白中表达；不要为了逐词配齐而闪入一张来不及读的新卡。

## 字体、背景与容器

字体角色按题材决定：判断词可用黑体，开放的概念/比喻可尝试宋体或其他适配的字形；对白保持清晰。不要把字号、全粗体与圆角标签当成唯一层级。系统字体不打包分发。

暗场负责照片/情境和焦点，浅纸面负责关系组织。可以在一段内从具体影像切入结构，但不强制双色背景或网格。纹理固定并低幅，阴影为对象提供接触关系；不让粗描边、网格、光晕占据注意力。

照片框承载照片，文档框承载文档，屏幕框承载软件/示意界面。框、状态栏、按钮要有用途；不要把浏览器装饰加到每段，或用装饰英文假装资料。示意界面只显示原话所需的信息，不伪造真实软件结果。

## 可执行模块与验证

`scripts/editorial_materials.py` 提供 `surface`、`make_plate`、`draw_plate` 和 `overlap_fraction`，供项目逐帧合成。它保留调用方素材与资产ID，支持完整容纳/显式裁切、简单顶栏、软阴影、二维旋转和退焦。不能给 render.py 填入这些函数名。

```python
plate = make_plate('example-photo', photo, (660,390), fit='contain')
box = draw_plate(frame, plate, (660,350), angle=-2)
# protected_box 由实际画面观察/跟踪提供；不是自动人脸检测。
overlap = overlap_fraction(box, protected_box)
```

新模块不生成照片，不生成真实动作，不自动识别主题、焦点或人脸，不把几何碰撞通过当作美感通过。既有 scene_camera、editorial_motion 仍用于连续轨迹和明确的取景目标。

同段验证需保留旧版及相同原声；记录素材改变、主次、手机可读性、强调时机与运动检查。实际对照应能看见素材及解释的改进，而不只有新版本号或更新说明。未经用户认可仍是候选。
