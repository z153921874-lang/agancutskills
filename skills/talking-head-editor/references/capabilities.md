# 教程映射与v2能力

参考用户的18分14秒教程，依据抽帧、屏幕字幕及操作轨道，未逐段试听。描述实际工具能力，不是鼠标步骤重演。

| 教程效果 | 当前状态 | 条件与限制 |
|---|---|---|
| 粗剪、拼接、保留原声 | 已实现，12段切片测试 | v2.1支持词级字幕重映射及切词警告；气口与语义仍需声音复核 |
| 识别字幕 | 本地Whisper base实测20秒中文 | 术语、断句和词时间需校对 |
| 标签/花字弹出、滑入、旋转、淡出 | 已实现，动画与真实画面检查 | 同款字体/模板需原资源 |
| 平滑推拉、中心移动 | 已实现，主体面积变化测试 | 防止裁切字幕、脸和商品 |
| 标签跟头移动 | MIL选框＋关键帧已实测3秒 | 非身份跟踪，遮挡/切镜/漂移需重选框 |
| 抠像、描边、发光 | 实验性，透明MOV已实测 | 多人可能一起保留，边缘/动作需检查 |
| 字在人后 | 已实测分层合成 | 需同源时间、同几何的合格透明前景 |
| 黑底小人 | 黑底片＋透明人物＋原音的路径已具备 | 已制作3秒黑底双人样片；内嵌字幕/标识可能残留，不是干净单人分割 |
| 聚光商品/人物 | 移动椭圆聚光已实测 | 自动跟随需位置数据，不支持任意手绘蒙版 |
| 模糊背景＋对比卡片 | 多层图片/视频与圆角描边已实测 | 自行指定版式，标签必须对应正确人物 |
| 照片倾斜、旋转与焦点切换 | v2.7 平面卡片旋转、分段透明度 | 保留外框与卡角，仍需人工规划主体和切换时间；不等于三维翻页 |
| 音效/配乐/淡入淡出 | 已实现，频率幅度测试 | 同款资源需文件，v2.1可显式开启人声压低配乐；以合成音频验证 |
| 同款火焰/故障片段 | 能合成已有素材 | 不自带教程资源，不保证同款 |
| 大头/搞怪五官 | 未实现 | 需脸部变形算法或剪映同款 |
| 任意手绘遮罩/自动精细商品跟随 | 未实现通用版本 | 只有椭圆聚光和选框跟踪 |
| 可编辑剪映工程 | 可选旧技能路径，未验证 | 需版本/接口/资源兼容测试 |
| 逐次代点剪映 | 当前不可用 | 需原生桌面通道 |

无法从教程恢复干净原片、独立原音或原工程，不能保证像素一致或一次达到讲师手调水准。升级定位是“可执行更多包装，智能部分需复核”，不是全自动复刻。
