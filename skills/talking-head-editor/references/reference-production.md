# 接近《反解》的视觉叙事制作

用户明确选择《反解》或同类混合讲解风格时使用。默认交付应体现逐句视觉设计、素材准备和关系表达。源视频是已剪访谈，也应为关键概念设计新增画面；保留原观点与上下文，并善用原片反应镜头。

## 先定具体画面，再安排效果

为关键语义单元写出：原话、观众该理解的关系、人物/物体或证据、信息出现顺序、镜头运动终点、回到真人的理由。只写“加字幕、加卡片”还不足以执行。

以养老话题为例：

- 照护者也变老：照护者和被照护者先后出现，明确谁照护谁，再提示双方都需要支持。
- 寿命与能力：时间图标和人物体力分别出现，用“不等于”表达关系；不要凭空画数值增长曲线。
- 社会支持：家庭、社区、专业服务逐项进入同一张图，连接到照护需求。图示为讨论框架，不冒充各地实际服务供给。

可以调用motion_scene.py制作这些基础动态关系画面；更复杂内容应按主题制作人物/实物/资料素材，不把所有段落都替换成图标卡片。原话本身有情绪时留真人，让表情和停顿完成表达。

## 素材工作不能被跳过

分镜中需要的资料、B-roll、人物卡和情境示意，分别列出已取得、待取得、待制作和回退方式。主动完成可用工具范围内的搜集与制作。证据必须有来源；AI场景只作示意。没有合适素材时，说明具体缺口和成片影响，不能把“没有准备素材”描述成“已经按参考风格完成”。

优先丰富承担任务的画面类型：证据局部、关系示意、实际动作、真人判断。根据主题选择，不强求固定素材比例或每隔几秒换一次。

## 主画面承载重点

重要资料/机制可以占据大部分画面；全屏覆盖原字幕时，先校对并重建该区间对白字幕，再回到原片。不能因为原片自带字幕就永远只在角落放小卡。

不默认把全片缩小并在窄黑边放小标题。使用真人全幅、完整信息图、局部证据特写等不同构图，让重点进入正常观看区域。源标识、人物、字幕和资料来源的保留方式分别检查。

关键词与章节标题分工：章节负责定位，少量关键词跟着论述重点进入主画面；按实际字数与手机预览检查字号、停留和遮挡。图形内部的出现、连线和结论应跟随原声，不能让所有元素一开始就摆满。

## 代表段与全片复核

从实际原声中选择包含“真人→解释画面→真人”的代表段先制作，检查后自主迭代并继续完整成片。除非用户要求审核，不设置必须等待确认的关卡。只有升级请求时，可以用短片工具演示交付；明确其不是全片效果证明。

交付前运行reference_review.py读取已验证render计划，然后逐项人工回答提示，并制作参考对照记录：

| 维度 | 必须回答的问题 |
|---|---|
| 开场 | 具体疑问与反差是什么？哪一个画面帮观众抓住它？ |
| 文案推进 | 删减后的每段如何接到下一段？有无失去前提？ |
| 视觉解释 | 哪些画面表达了因果/对照/关系，而不仅是重复原话？ |
| 素材与构图 | 不同任务是否使用了合适素材与版式？有无无意义的装饰镜头？ |
| 回调 | 前段重要对象是否值得在后段再次出现，以形成比较或结论？ |
| 声音 | 剪口、重音、停顿是否已实际回听？没有新增音乐是否是有意选择？ |
| 剩余差距 | 哪些仍只是基础图解，哪些资源缺失，哪些效果未完成？ |

自动报告是事实清单与提示，不是审美评分。不能通过增加卡片数量、视频文件数量或大画面时长来“刷过”验收。技术可播放与接近参考片分别报告。

## 已观察到的失败与修正

此前3分16秒访谈版只有3张静态总结卡、约30.2秒叠层与9段边缘标题。这种结果应称为访谈精剪基础版。后续同类请求须在分镜、素材与语义可视化上实质推进，不能仅调整淡入时长后继续宣称达到《反解》的视觉叙事效果。
