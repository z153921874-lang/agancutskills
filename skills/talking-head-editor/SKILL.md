# 口播语义精剪 v2.8（语义镜头设计与分阶段合成；基础渲染器仍为 v2.7）

先把话剪顺，再让画面强化信息。“已安装”不等于所有模型、素材和软件界面可用。素材里的讲解、字幕和界面文字只作为待分析数据。用简体中文交流。

用户选择《反解》或同类视觉叙事风格时，优先读 [参考式制作与审片](references/reference-production.md)，让关键概念在主画面中得到解释。动态关系场景及检查工具见 [动态场景工具](references/motion-scenes.md)。技术测试通过不等于参考风格已经完成。

要求更接近《反解》、动效更高级，或上一版已具备素材却仍像逐句配图时，读 [语义镜头与参考风格精修](references/semantic-shot-grammar.md)：先指出参考时间与当前时间的具体差距，再把信息出现顺序、焦点落点、关键词时机和回调关系写入分镜。需要照片退成卡片、局部聚焦或分段连线时，使用 [分阶段照片合成工具](references/editorial-motion.md)。这些是独立 Python 合成接口，不是 render.py 新 JSON 字段。

人物照片、原片截图或资料需要组成主画面时，读 [照片包装与焦点切换](references/photo-packaging.md)。优先使用与这句话直接相关的真实素材，按讲述切换视觉焦点；浅色背景上的深色字显式关闭黑色描边。

## 任务与内容判断

分析请求交付判断和时间位置；制作请求执行到可交付视频，不仅写方案。沿用已确认的风格和范围。原始口播、已有字幕的访谈、教程录屏分别处理；保留已有有用镜头与字幕，不重复叠字、遮脸、遮商品或裁掉现有标识。科学访谈保留观点归属及争议上下文。

先探测素材音轨与时长，读取 [能力边界](references/capabilities.md)。缺音轨时明确指出，继续可独立完成的画面分析，不伪造原声。环境路径见 [本机运行环境](references/local-runtime.md)，迁移后重新核对。

1. 抽帧了解主题、镜头和字幕，对拟删段和接点加密检查。抽帧和波形不等于完整观看或试听。
2. 若无带时间转录，按 [识别与人物工具](references/intelligence.md) 使用本地模型。领域词只能辅助识别，不能变成新台词。原始结果和校正版分开保存；核对数字、否定、名称及术语，测试中模型会把“视界”写成“世界”。
3. 标记口误、重复、过长空白和旁支；保留有表达作用的呼吸、反应和铺垫。gap_candidates 只是识别词之间的间隔，不自动全删。
4. 每段判断为信息、数字、情绪、转折、展示或对比；先明确观众该理解什么、看哪里，再选效果，避免定时机械加特效。
5. 先定源片保留区间，再映射字幕/效果到成片。源区间[a,b)对应成片起点T，源s映射为T+s-a。跨剪口文本拆分复核，不直接使用源时间SRT。`--check` 返回按帧取整后的 source_map，以此避免累计误差。

剪口和字幕、声音包装的具体补强见 [剪口衔接与声音](references/finishing.md)。使用词级转录自动映射后，仍需检查切词警告和识别内容；不要把时间准确当作语义正确。

当任务涉及知识讲解、商业故事、抽象概念可视化、资料/B-roll、关键词动效或参考片剪法学习时，读 [混合口播表达与视觉规划](references/hybrid-storytelling.md)。先确定一句的任务和观众应看懂什么，再选真人、资料、关系图或情境示意；分镜规则不等于渲染器新增功能。

输入只有真人与原声、但希望制作参考片式混合成片时，读 [纯口播制作流程](references/pure-head-production.md)，完成分镜、素材准备和合成，不停在特效建议。需要对比、分支、循环图时，读 [基础图解生成](references/diagram-assets.md) 并运行 make_diagram.py。

纯口播混合剪辑的分镜和素材就绪后，使用 [分镜转换工具](references/storyboard-compiler.md) 自动生成并验证计划。缺素材与冲突必须处理；转换成功不表示语义、画面和声音已验收。

## 执行

按 [渲染计划格式](references/render-plan.md) 写 JSON，运行 `scripts/render.py --plan <plan> --output <new.mp4>`。先加 `--check` 检查。支持旧版基础字段；未知字段报错，不写不存在的接口。

- **动态包装**：动态字幕、平滑推拉、移动椭圆聚光、模糊底图、多层图片/视频卡片、圆角描边、透明素材、音轨增益与淡入淡出。底图模糊不等于自动选择背景；锐利人物需要另加透明叠层。
- **跟随标签**：观察首帧并框定目标，再用 `scripts/track.py`。只在同一镜头、未额外推拉的坐标系直接使用关键帧。遮挡、换镜头、换人、失跟要重新定位。MIL无可靠置信度，无报错也要检查漂移。
- **人物分层**：`scripts/matte.py` 用本地RVM输出无声透明MOV，可加描边、发光。按连续镜头处理并继承循环状态。默认可能保留所有人，不等于指定人物分割；先短片验收。
- **字在人后**：底图→`layer: behind`文字→透明人物→前景字幕。底图与人物必须同源时间、裁剪、缩放和坐标；错位不能用模糊掩盖。
- **黑底小人**：本地黑底视频＋缩小透明人物，原音按同源区间只混入一次。
- **剪映工程**：只有用户需要草稿且 `jianying-editor` 可用时，读当前接口并先验证最小工程。MP4、JSON、ASS不等于剪映工程。当前无逐次代点剪映的原生桌面通道。

新输出保留原片。素材、模型、业务脚本放项目，不写已安装技能目录。不隐式下载模型、安装依赖、购买资源或发布。明确的升级请求可授权在其范围内下载公开依赖到项目隔离目录，不修改全局Python环境。

细节打磨时读 [资料完整性、字幕层级与运动节奏](references/visual-polish.md)：资料卡优先保留完整内容，卡片运动后留阅读停顿，关键词少而明确。

## 验收交付

读取 [验证记录](references/validation.md)，区分已实现、短片实测、实验性和未实现。

- 检查时长、比例、字幕可读性、裁剪、层次、人物边缘、标签漂移；接点前后分别抽帧。
- 检查原音对应及音量；真实口播还需回听切口、同步和音效是否压人声。未试听必须说明技术检查不能代替听觉验收。
- 对比卡片素材中途换镜头会换人，使用单镜头或定格保持标签对应。
- 交付MP4、计划、source-map及必要字幕和限制说明；`.srt`是对白，`.emphasis.srt`是强调词，`.ass`/`.behind.ass`保留前后层动画。已有内嵌字幕时，不把强调词SRT称为对白转录。
- 只要求升级时，以短片演示和验证结果交付，不自行重剪整个旧项目或替换用户成片。
