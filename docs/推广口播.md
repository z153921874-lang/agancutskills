# agancutskills 项目推广口播

建议标题：我把口播剪辑做成了一个 AI Skill

适合真人出镜，穿插实际剪辑前后对比。正文约90–120秒，按实际语速调整；配画面建议不作为台词朗读。

## 可直接录制的口播

一条口播录完了，怎么把它剪得更好看、更好懂？

我是阿甘。我把自己反复调整的口播剪辑流程，整理成了一个给 AI 助手用的 Skill，叫 agancutskills。

它会引导 AI 先梳理你在讲什么，再规划剪口、字幕和画面，调用本地工具完成合成。

第一，把话剪顺。清理口误、重复和拖沓空白，同时保留有用的停顿、表情和反应，让真人讲述有节奏。

第二，把抽象概念变成能看懂的画面。比如说“我的肠胃比我上班还准时”，就可以用一个胃去打卡的示意画面，配上扫描、确认的状态变化，让这个比喻更直观。

第三，让素材接得起来。同一张图可以先出现在人物旁边，再放大进入解释画面；讲对比时，旧对象退小，新对象成为重点，观众还能看清两者的关系。

真人表达和解释画面，各有各的任务。这套流程适合生活口播、知识讲解，也适合商品介绍。

使用时，把它装进 Codex，配好本地剪辑环境，再给出视频路径和要求，就可以让 AI 按这套流程协助剪辑。转录、素材和最终效果仍然需要检查，联网找素材和生成图片也取决于你使用的工具。

我已经把项目上传到 GitHub，名字就是 agancutskills。你可以下载试用，觉得有帮助就点个 Star，也欢迎把实际效果和遇到的问题反馈给我，帮我把它继续改好。

## 配画面建议

| 口播位置 | 建议画面 |
|---|---|
| 开场问题 | 真人出镜，紧接同一句口播的原片与成片对比 |
| 项目名称 | 真人旁短暂出现 agancutskills 名称，随后回到实际效果 |
| 把话剪顺 | 展示真实剪口、字幕和表情保留的片段，避免模拟不存在的界面 |
| 胃去打卡 | 使用实际候选成片的读取到确认片段，保留 AI 示意标识；二维状态叠层不能称真实刷卡动作 |
| 素材接得起来 | 展示实际真人旁小卡放大进入解释画面的连续片段，再展示磐石与车流对照 |
| 安装与收尾 | 简短真实安装步骤或仓库页面录屏，清楚显示仓库名与下载入口 |

先展示实际效果，再解释项目。不要将制作计划、能力测试或本地路径当成面向观众的字幕。录制仓库或安装画面前隐藏个人目录、账号信息及无关窗口。

## 简短项目介绍

agancutskills 是给 AI 助手使用的口播剪辑技能与本地工具集，涵盖语义剪口、关键词字幕、素材规划和二维视觉合成。它帮助创作者保留真人表达，并用具体对象、状态变化和连续画面解释内容，适用于生活口播、知识讲解与商品介绍。

项目需要本地剪辑环境；素材检索与图片生成依赖宿主工具。下载包包含技能和工具，不含用户原片、参考视频、第三方素材、字体或模型。
